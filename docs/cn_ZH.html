claude-code·queue
English

排队，不插队。

Claude Code 的消息队列。忙时输入 /queue …，消息会先等候——本轮跑完后才执行，而不是被打断。

不用 /queue — 会打断
claude-code
用 /queue — 会等待
claude-code

安装

$ curl -fsSL \
  https://jinhuang712.github.io/claude-code-queue/install.sh \
  | bash
# 重启 Claude Code — 就有了裸 /queue

为什么

按回车，不该把当前任务带偏。

Claude Code 忙时你发的普通消息会在下一个 tool-call 边界被插进去——它会打断、带偏正在跑的任务。但对已注册的 slash command，Claude Code 原生就会等到整轮结束才投递。claude-code-queue 做的只是把 /queue 注册成一条命令：排队由原生调度器完成，命令正文则让 Claude 在你离开时也能把延后的请求稳妥跑完。

排队多条

排好几条，一轮弹一条

忙时发的每一条 /queue，都会按顺序进入这次会话的先进先出队列——本轮一结束，排在最前面的那条就自动开始。

FIFO — 一轮一条
claude-code
没有在跑的任务？直接执行。
claude-code

没有 hook、没有守护进程、没有存储——只有一个命令定义。按 ↑ 可编辑排队中的消息（原生功能）。原理详见 仓库。
