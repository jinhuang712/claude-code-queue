claude-code-queue — how it works

Rendered mermaid. If this looks right, the raw block below is exactly what goes into the README.

flowchart TD
    Start([User submits a prompt]) --> Q{"/queue ... ?"}

    Q -- "no — normal prompt" --> BN{"session busy?"}
    BN -- "yes" --> Nat["note native-pending
(only if our queue non-empty)"]
    BN -- "no" --> M1["set busy marker"]
    Nat --> M1
    M1 --> Claude[["Claude works on it"]]

    Q -- "yes — /queue X" --> BQ{"session busy?
( status = busy  AND  marker )"}
    BQ -- "yes" --> Wait[("waiting area
per-session · FIFO")]
    BQ -- "no — idle" --> Now["allow → handle X now
(one normal turn)"]
    Now --> Claude

    Claude -- "turn ends" --> Stop{"Stop hook"}
    Stop --> Eq{"queue empty?"}
    Eq -- "yes" --> Idle(["idle — clear marker + native"])
    Eq -- "no" --> Np{"native-pending?"}
    Np -- "yes" --> Yld["yield → real prompt
runs next"]
    Np -- "no" --> Pop["pop oldest (FIFO)
🔔 queued message popped
→ deliver to Claude"]
    Pop --> Claude
    Yld -.->|real prompt| Claude
    Wait -.->|drained by Stop| Eq
