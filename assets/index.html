claude-code·queue
中文

queue, not interrupt.

A prompt queue for Claude Code. Type /queue … while Claude is busy and the message waits — it runs after the current turn, instead of being injected at the next tool-call boundary.

Install

$ /plugin marketplace add jinhuang712/claude-code-queue
$ /plugin install claude-code-queue@claude-code-queue
$ /reload-plugins
/queue then run the tests and fix failures
📝 Queued (runs after the current turn, 1 pending): then run the tests…
… Claude keeps working, uninterrupted …
🔔 queued message popped (queue empty): then run the tests and fix failures
✓ auto-started

Why

Pressing Enter mid-turn shouldn't derail the turn.

By default, a message sent while Claude Code is mid-turn is injected at the next tool-call boundary — it interrupts and redirects the running task. claude-code-queue adds the missing queue: the message waits, then runs when the turn ends, in the same session.

Behavior

How a queued message is treated

Busy → waiting area

The current turn is not interrupted. The message is popped and auto-started when it finishes.

FIFO, one per turn

Multiple items drain in order, one turn each, in the same session — never stolen by another session.

Real prompts preempt

A normal (non-/queue) prompt submitted while busy always runs before deferred items.

Idle → immediate

Nothing to wait behind — handled at once as a normal turn.

Examples

Using it

Queue a follow-up while busy

Claude is mid-turn. Line up the next task without cutting in:

/queue then run the test suite and fix anything that breaks
📝 Queued (runs after the current turn, 1 pending): then run the test…

Line up several (FIFO, one per turn)

/queue update the README with the new flag
/queue commit and push

A real prompt preempts

Normal prompts run before deferred ones:

/queue polish the docs later
actually fix this blocking bug first   # runs first

Inspect / clear

/queue          # show this session's queue
/queue clear    # empty it

Distributed as a native plugin — no settings.json editing, no npx. See the repo for the full mechanism, design notes, and tests.
